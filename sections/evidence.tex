\paragraph{The test}
For a query and a check, an open model (Gemma-4-31B-it) edits only the spans the check flags, and validators reject an edit that adds facts or misses the check.
The reference rewords the same spans to the same length, or, for checks without such a placebo, is the unedited page ($^{\circ}$ in Figure~\ref{fig:result}).
Two open judges (Gemma-4-12B-it and Qwen3.8-27B) answer the query from 4 sources, 8 times each with the page in each slot twice, and the page's \emph{citation score} is $(5-r)/4$ when it is the $r$-th source cited, else 0.
A result needs 30 or more queries, and tests are Holm-corrected within their family.
``No effect larger than 0.03'' means the 90\% interval lies inside $\pm 0.03$, so smaller effects stay possible (plans, code and data: footnote~\ref{fn:links}).

\paragraph{Eleven checks}
Of single changes, only the two that add the reader's own words near the top clearly raised the score (Figure~\ref{fig:result}a).
\emph{Your reader's words up top}, a candidate check the tool added because it helped, works the question's missing words into the title and opening ($+0.035$ against its placebo; replication: too few pages).
\emph{Target questions answered} was tested as the reader's question as a heading under the title, over a copy of the page's best-matching sentence, made by rule: the \emph{question section} ($+0.027$ against the unedited page, 95\% CI $[+0.010, +0.043]$, Holm $p = 0.006$; replication $+0.036$).
All fixes together, which include the question section, also helped ($+0.049$).
The heading form added nothing: the question as a heading did no better than the same text set as plain ($+0.003$; replication $-0.001$).
A section of the same size without the reader's words did not clearly beat the unedited page ($+0.010$; replication $-0.012$; shown without a verdict).
Against that section the question section helped on the replication set ($+0.048$) and was inconclusive on the main set ($+0.017$).
Re-edited by another model with one judge swapped, the reader's-words gain kept its sign ($+0.029$) on 29 queries, one short of our minimum.
A follow-up added 180 queries and one more editing attempt for the checks with too few pages.
Over the 260, question headings, cited sources and a direct answer first showed no effect larger than 0.03, as did lists over the first 80 and a candidate that copied the page's definition under the title.
Attributed quotes were inconclusive, and tables, statistics and comparisons still had too few pages.

\paragraph{When the writer has to guess}
The gain held on new queries, and a keyword helped, but less.
Both gains above used the reader's exact question, which a writer rarely sees.
A last test reran the question section on those 180 new queries, which the first test never used.
It then built the section from two guesses the tool offers: a keyword, here the question's two rarest key words, and a question the same editor model wrote from it with the tool's prompt; answers were still judged against the true question.
The exact question helped on the new queries ($+0.039$, 95\% CI $[+0.023, +0.056]$, $n = 115$; $+0.035$ pooled with the first test's queries, $n = 169$), and the reader's missing words worked into the top held there too ($+0.036$ against their placebo, $n = 74$, shown without a verdict).
Over all 260 queries the keyword helped against the unedited page ($+0.016$) and against a section without the reader's words ($+0.018$; Holm $p = 0.006$ for both).
Yet the exact question beat it by $+0.019$, 95\% CI $[+0.008, +0.031]$; by the rule we set before the run, an interval above zero means the guess \emph{falls short of the exact question}.
On the new queries alone the keyword kept about two thirds of the gain (shown without a verdict).
Part of the edge is the exact query string, which the judge's prompt also shows: the exact question beat a section with all its key words but not the string by $+0.014$ (shown without a verdict).
The model's question showed no effect larger than 0.03 ($+0.008$), and neither did the keyword's missing words worked into the top ($+0.004$ against their placebo).
On the 60-query replication set both guesses beat a section without the reader's words ($+0.025$, $+0.028$) and showed no effect larger than 0.03 against the unedited page.

\begin{takeaway}
Each gain on the main set carries the plan's note: possibly through length or query-word overlap.
Length alone did not do it: the reader's words beat same-length controls ($+0.035$; a keyword $+0.018$).
For writers that is the point: the formatting they are sold did not clearly move citation, and the reader's vocabulary did.
\end{takeaway}
