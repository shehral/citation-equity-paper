\paragraph{The test}
For a query and a check, an open model edits only the spans of the target page that the check flags, and validators reject an edit that adds facts or misses the check; the placebo rewords the same spans to the same length.
Two open judges answer the query from 4 sources, 8 times each with the order shuffled, and the page's \emph{citation score} is $(5-r)/4$ when it is the $r$-th source cited, else 0.
A result needs 30 or more queries, tests are Holm-corrected within their family, and ``no effect larger than 0.03'' means the 90\% interval lies inside $\pm 0.03$ (plans, code and data: footnote~\ref{fn:links}).

\paragraph{Eleven checks}
Of single changes, only the two that add the reader's own words near the top clearly raised the score (Figure~\ref{fig:result}a): the reader's question as a section under the title ($+0.027$, 95\% CI $[+0.010, +0.043]$, Holm $p = 0.006$; replication $+0.036$), and the question's missing words worked into the title and opening ($+0.035$ against its placebo).
The words carry the gain, not the form: the question as a heading did no better than the same text set as plain ($+0.003$; replication $-0.001$), while the plain text beat the untouched page ($+0.023$; $+0.037$).
With another editor and other judges, the reader's-words gain kept its sign ($+0.029$, $n = 29$).
A follow-up added 180 queries for the checks with too few pages: over 260, question headings, cited sources and a direct answer first showed no effect larger than 0.03, as did lists over 80; attributed quotes were inconclusive, and tables, statistics and comparisons still had too few pages.

\paragraph{When the writer has to guess}
Every edit above used the reader's exact question, which a writer rarely sees.
A last test reran the question section on those 180 new queries, which the first test never used, then built it from two guesses the tool offers: a keyword, here the question's two rarest key words, and a question a local model wrote from it; answers were still judged against the true question.
The exact question helped on the new queries ($+0.039$, 95\% CI $[+0.023, +0.056]$, $n = 115$; $+0.035$ pooled with the first test's queries, $n = 169$), and the reader's missing words worked into the top held there too ($+0.036$ against their placebo, $n = 74$, shown without a verdict).
The keyword helped against the untouched page ($+0.016$) and against a section without the reader's words ($+0.018$; Holm $p = 0.006$ for both), but the exact question beat it by $+0.019$ $[+0.008, +0.031]$, so by the rule we set before the run the keyword loses the gain; on the new queries it kept about two thirds of it.
Part of that edge is the exact query string, which the judge's prompt also shows: the exact question beat a section with all its key words but not the string by $+0.014$.
A question a local model wrote from the keyword showed no effect larger than 0.03 ($+0.008$), and neither did the keyword's missing words worked into the top ($+0.004$ against their placebo).

\begin{takeaway}
Every gain here tracks the reader's words: once changes in length and in the count of query words are regressed out, what is left includes zero.
That is the point for writers: the formatting they are sold did not move citation, and the reader's vocabulary did.
\end{takeaway}
