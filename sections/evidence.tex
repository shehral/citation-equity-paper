\paragraph{The test}
For a query and a check, an open model (Gemma-4-31B-it) edits only the spans the check flags, and validators reject an edit that adds new numbers, links or names, or misses the check.
The reference rewords the same spans, at the same length for a rewrite and with nothing inserted for an additive check, or is the unedited page ($^{\circ}$ in Figure~\ref{fig:result}).
Two open judges (Gemma-4-12B-it and Qwen3.8-27B) answer the query from 4 sources, 8 times each with the page in each slot twice, and the page's \emph{citation score} is $(5-r)/4$ when it is the $r$-th source cited, else 0.
A result needs 30 or more queries, and tests are Holm-corrected within their family.
``No effect larger than 0.03'' means the 90\% interval lies inside $\pm 0.03$, so smaller effects stay possible; contrasts the plan left unjudged read \emph{no verdict} (plans, code and data: footnote~\ref{fn:links}).

\paragraph{Eleven checks}
Of single changes, only the two that add the reader's own words near the top clearly raised the score (Figure~\ref{fig:result}a).
\emph{Your reader's words up top}, a candidate check the tool added because it helped, works the question's missing words into the title and opening ($+0.035$ against its placebo; replication: too few pages).
\emph{Target questions answered} was tested, by rule, with the reader's question as a heading under the title over a copy of the page's best-matching sentence: the \emph{question section} ($+0.027$ against the unedited page, 95\% CI $[+0.010, +0.043]$, Holm $p = 0.006$).
All fixes together, which include the question section, also helped ($+0.049$).
The heading form added nothing: the question as a heading did no better than the same text set as plain ($+0.003$).
Against a same-size section without the reader's words, the question section helped on the replication set ($+0.048$) and was inconclusive on the main set ($+0.017$).
Re-edited by another model with one judge swapped, the reader's-words gain kept its sign ($+0.029$) on 29 queries, one short of our minimum.
A follow-up added 180 queries and one more editing attempt for the checks with too few pages: over the 260, question headings, cited sources and a direct answer first showed no effect larger than 0.03, as did lists over the first 80 and a candidate definition sentence under the title; quotes were inconclusive, and three checks still had too few pages (Figure~\ref{fig:result}a).

\paragraph{When the writer has to guess}
The gain held on new queries, and a keyword helped, but less.
Both gains above used the reader's exact question, which a writer rarely sees, so a last test reran the question section on 180 new queries, which the first test never used, and then built the section from two guesses the tool offers: a keyword, here the question's two rarest key words, and a question the same editor model wrote from it with the tool's prompt; answers were still judged against the true question.
The question section helped on the new queries ($+0.039$, 95\% CI $[+0.023, +0.056]$, $n = 115$), and \emph{Your reader's words up top} held there too ($+0.036$ against its placebo, $n = 74$, no verdict).
Over all 260 queries the keyword helped against the unedited page ($+0.016$) and against a section without the reader's words ($+0.018$; Holm $p = 0.006$ for both); the first gain rests mainly on the second judge (Qwen3.8-27B $+0.021$; Gemma-4-12B alone $+0.010$, not significant).
Yet the exact question beat it by $+0.019$, 95\% CI $[+0.008, +0.031]$: by the rule set before the run, the guess \emph{falls short of the exact question}.
On the new queries alone the keyword kept about two thirds of the gain (90\% CI 0.41 to 0.93; no verdict).
Part of the edge is the query string itself, which the judge's prompt also shows (Figure~\ref{fig:result}b, bottom row, no verdict).
The model's question showed no effect larger than 0.03, and neither did the keyword's missing words up top against their placebo.

\begin{takeaway}
Each main-set gain carries the plan's note, possibly length or query-word overlap, but length alone did not do it: the reader's words beat same-length controls ($+0.035$; a keyword $+0.018$).
For writers that is the point: the formatting they are sold did not clearly move citation, and the reader's vocabulary did.
\end{takeaway}
